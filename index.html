TRAINING GUIDE

How to complete the fictional case exercise

  1. Open Source Review. Click report rows to read the summaries and identify the source type.
  2. Use the relevance field to rate whether a report helps answer the case objective. Mark reports reviewed.
  3. Check Entity Index, Association Review, and Event Timeline. These organize references, but do not prove intent.
  4. Write findings with supporting report IDs. State uncertainty and what requires corroboration.
  5. Draft an intelligence brief, then print or save it as a PDF.
Training use only. All names and events are invented; this system stores no sensitive records and is not an operational intelligence platform.
